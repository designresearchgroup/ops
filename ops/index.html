About Giggy

Giggy is your cash partner — a CV creation & delegation tool that validates opportunities, screens you in a qualifying interview, writes interview-defensible resumes and cover letters (exported as real, ATS-parseable PDFs), and manages a pipeline that aligns proven skills to current job-market trends. It enforces the operating rules: fit analysis before generation, moat-led framing, true-keyword mirroring, ATS-safe output, and a post-generation guardrail check against the HAVE/DON'T lists.

Static frontend served at jamesecoleman.com/ops/ and shipped to GoDaddy over FTPS on every push to main. Data lives in Supabase Postgres when connected (localStorage otherwise); the Claude key stays server-side in a Supabase Edge Function (or the GoDaddy PHP proxy). See README.md.
